VERIFIED RESULTS — Global Baryonic Boundary Scaling Relation (SPARC)
=====================================================================
These are the numbers `python src/sparc_validation.py` and
`python src/model_comparison.py` should reproduce when run against the
raw public SPARC data (Lelli, McGaugh & Schombert 2016, AJ 152, 157),
downloaded via `python src/download_data.py`.

                              same reason as the others: missing R_HI,
                              NOT because it is a dwarf)
  Retained sample                                171 galaxies

     N=3344 and slightly different numbers — see the note at the
     bottom of this file.)

Frozen model constants (see src/model.py)
------------------------------------------
  A0 = 0.339006   km/s * Msun^(-1/4)
  n  = 2.01362
  x0 = 0.44006
  Upsilon (M/L at 3.6um) = 0.5 Msun/Lsun, applied to L_[3.6] ONLY
  M_HI helium correction factor = 1.33

  These were obtained via global differential-evolution optimization
  (scipy.optimize.differential_evolution, strategy=best1bin,
  mutation=(0.5,1), recombination=0.7, tol=1e-12, popsize=25,
  maxiter=3000) minimizing RMS across all 3346 points simultaneously.
  Five independent seeds (1, 7, 42, 99, 2026) converge to identical
  constants to better than 1e-6 — reproduce this with
  `python src/fit_constants.py`.
